## Key Concepts

### ARD (Agent Requirements Document)
Structured markdown specification for the system you want agents to build. See examples/ and docs/ard-coach-guide.md.

### Swarms
Groups of specialized agents: Architecture, Implementation, Integration, Testing, Documentation (21 total agents).

### MCP (Model Context Protocol)
Inter-agent communication standard. Generated servers export tools for other agents to use.

### Skills
Portable markdown + code tools for Claude Code. Generated skills enable autonomous execution.

### Hooks
Bash/Python scripts triggered during Claude Code lifecycle (pre/post commit, pre/post build).
